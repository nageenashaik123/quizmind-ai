# 🧠 QuizMind AI

> **AI-Powered Subject-Based Quiz Generation and Student Performance Analytics Platform**

A full-stack web application that lets students generate personalised MCQ quizzes on any subject using AI, track their performance over time, and analyse their strengths and weak areas.

[![Node.js](https://img.shields.io/badge/Node.js-v25.x-green)](https://nodejs.org)
[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-16-blue)](https://postgresql.org)
[![License](https://img.shields.io/badge/License-MIT-purple)](LICENSE)

---

## ✨ Features

| Feature | Description |
|---|---|
| 🤖 AI Quiz Generation | Fresh MCQs generated by Gemini 3.8 Flash or Groq (LLaMA) on demand |
| 🏦 Question Bank | Every generated question is stored permanently as a fallback |
| 🔒 Authentication | JWT + bcrypt with email OTP verification |
| 📧 Email OTP | 6-digit codes via Gmail for registration and password reset |
| 📊 Dashboard | Subject-wise performance, difficulty breakdown, weak/strong areas |
| 🕘 Quiz History | Filterable list of all attempts with result and review links |
| 📖 Answer Review | Question-by-question review with correct answers and AI explanations |
| ⏱ Timed Mode | Auto-submit when the timer reaches zero |
| 🛡 Security | Backend scoring, ownership checks, no answer leaks to frontend |

## 🚀 Local Setup

### Prerequisites
- Node.js v20+
- PostgreSQL 14+
- Ollama (optional, for local AI fallback)

### 1. Clone and install

```bash
git clone https://github.com/YOUR_USERNAME/quizmind-ai.git
cd quizmind-ai
npm install
```

### 2. Configure environment

```bash
cp .env.example .env
```

Edit `.env` with your values:

```env
PORT=5000
DATABASE_URL=postgresql://postgres:YOUR_PASSWORD@localhost:5432/quizmind
JWT_SECRET=your_secret_here
JWT_EXPIRES_IN=7d

# Gemini (AQ. format key from Google AI Studio)
GEMINI_API_KEY=AQ.your_key_here
GEMINI_MODEL=gemini-flash-latest

# Groq
GROQ_API_KEY=gsk_your_key_here
GROQ_MODEL=qwen/qwen3.8-27b

# Ollama (local)
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=phi3:mini

# Gmail App Password
EMAIL_API_KEY=your_16_char_app_password
EMAIL_FROM=your@gmail.com
```

### 3. Set up the database

```bash
# Create database
psql -U postgres -c "CREATE DATABASE quizmind;"

# Run schema
psql -U postgres -d quizmind -f server/db/schema.sql

# Seed domains and subjects
$env:PGCLIENTENCODING="UTF8"
psql -U postgres -d quizmind -f server/db/seed.sql
```

### 4. Start the backend

```bash
npm run dev       # development (auto-restart)
# or
npm start         # production
```

### 5. Open the frontend

Open `client/index.html` with VS Code **Live Server** or any static file server.

Navigate to `http://127.0.0.1:5500/client/index.html`

## 🌐 REST API

### Auth
| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/auth/register` | Create account + send OTP |
| POST | `/api/auth/verify-otp` | Verify email OTP |
| POST | `/api/auth/resend-otp` | Resend OTP (rate limited) |
| POST | `/api/auth/login` | Login → JWT |
| GET  | `/api/auth/me` | Get current user |
| POST | `/api/auth/forgot-password` | Send reset OTP |
| POST | `/api/auth/reset-password` | Reset with OTP |

### Domains
| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/domains` | List all 4 domains |
| GET | `/api/domains/:id/subjects` | Get subjects for a domain |

### Quizzes
| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/quizzes/generate` | Generate quiz with AI |
| GET  | `/api/quizzes/:id` | Get quiz + questions (no answers) |
| POST | `/api/quizzes/:id/submit` | Submit answers → score calculated |

### Attempts
| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/attempts` | History (filterable) |
| GET | `/api/attempts/:id` | Single result |
| GET | `/api/attempts/:id/review` | Full review with answers |

### Analytics
| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/dashboard` | Complete analytics |
| GET | `/api/profile` | User profile + stats |

## 🔒 Security Notes

- Passwords hashed with **bcrypt** (12 salt rounds)
- JWTs verified on every protected request
- Quiz scores **always calculated server-side** — never trusted from frontend
- Correct answers never returned in quiz API responses
- OTPs hashed with bcrypt before storage
- SQL injection prevented with **parameterised queries** throughout
- API keys stored in `.env` — never committed to Git

## 📈 AI Provider Fallback Chain

```
Request → Gemini 3.8 Flash (primary, ~37s)
              ↓ (if fails/quota)
         Groq qwen3.8-27b (fallback, ~3s)
              ↓ (if fails)
         Ollama phi3:mini (local, ~3-15min on CPU)
              ↓ (if all fail)
         Question Bank (stored questions)
              ↓ (if bank empty)
         503 error with helpful message
```

## 🌍 Deployment

### Frontend → Vercel
1. Push `client/`, `css/`, `js/` to GitHub
2. Connect repo to Vercel
3. Set root to project root, output to `client/`

### Backend → Render
1. Connect repo to Render
2. Set build command: `npm install`
3. Set start command: `node server/server.js`
4. Add all environment variables from `.env`

### Database → Neon
1. Create a free Neon project
2. Copy the connection string
3. Set `DATABASE_URL` in Render environment variables
4. Run `schema.sql` and `seed.sql` once against Neon
